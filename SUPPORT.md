# Getting Support

Need help with KiloOS, building the pure Assembly bootloader, or understanding the UEFI Class 3 integration? Check the options below.

## Where to Find Help

1. **GitHub Issues:** 
   * Use issues primarily for bug reports and feature requests regarding the core Assembly source code.
2. **Documentation & Roadmap:**
   * Consult `ROADMAP.md` and codebase comments before asking foundational questions. Remember: **KiloOS is 100% Assembly**; there are no high-level wrappers or hidden abstractions to read through.
3. **Direct Contact:**
   * For critical questions or maintainer alignment, reach out to the BDFL (João) via the email listed in `CONTRIBUTORS.md`.
