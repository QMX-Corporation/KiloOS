## WHATS I CONTRIBUTE TO KILOOS?
1. Click in 'Fork' Botton in the Site.
2. Click in 'Continue' in next Window of 1 Step.
3. Uses the git clone for clone your Fork.
4. Create a branch (e.g., git checkout feature/new-ideas)
5. Your alterations!
6. Commit (git commit -m your-message)
7. Push your Commit to your Fork.
8. Open a PR in the Site.
