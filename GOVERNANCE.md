# KiloOS Governance

## Project Leadership: The BDFL Model

KiloOS is maintained and governed under the Benevolent Dictator For Life (BDLF) model. 

### The BDFL
* **João Guilherme da Silva Freitas Lima** (GitHub: `dev12124`) is the founder, lead architect, and BDFL of KiloOS.
* The BDFL holds final decision-making authority regarding the project's architecture, roadmap, direction, and code inclusion. 
* Because KiloOS is built entirely in **pure Assembly** targeting UEFI Class 3 environments with zero abstraction compromises, architectural purity and raw performance take absolute precedence.

### Decision Process
1. **Proposals & Contributions:** Contributors may open pull requests or issues via GitHub.
2. **Review:** All Assembly code is rigorously reviewed for correctness, compliance with x86_64 UEFI calling conventions, and adherence to pure low-level constraints.
3. **Final Authority:** If there is a dispute or architectural ambiguity, the BDFL makes the definitive ruling.
